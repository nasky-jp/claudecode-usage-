# 朝ブリーフ Skill

## 手順

1. 当日の朝チェックが未実行なら実行する(要 ANTHROPIC_API_KEY / ネットワーク):
   ```bash
   python3 -m market_flow.morning_check
   ```
   - すでに `market_flow/reports/YYYYMMDD_morning_check.md`(今日の日付)があれば再実行せず、それを読む(API課金の二重発生を避ける)。
2. 監視リストだけ欲しい場合:
   ```bash
   python3 -m market_flow.screener
   ```
3. ダッシュボードを更新:
   ```bash
   python3 -m market_flow.dashboard
   ```
4. ユーザーへの返答は次の3点に絞る:
   - 今日の方向感(強気/弱気/中立)と理由1行
   - 監視リスト上位3銘柄(コード・銘柄名・前日比)
   - 保有中ポジションへの注意点(あれば)

## ルール

- 売買の推奨はしない。「監視候補」という言葉を使う。
- データ取得に失敗した銘柄がある場合は正直に伝える。
- 発注・決済はユーザーの明示的な指示があるまで日誌に書かない。
